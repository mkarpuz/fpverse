# fpverse
This is a landing page project as part of The Odin Project curriculum. The FPV Verse was just an idea of a possible website I had in mind to build an FPV community.

- As this was a learner project, I didn't want to spend much time on the visuals. The images are generated by AI, the ChatGPT SOL 5.6 model specifically, although the time spent was not that short, with lots of attempts :)

- This actually took a lot more time than expected, my first time coding from scratch without any AI tools :) It took me around 10 hours to build this page. I had the most fun tackling small problems and going back to check the basics, and I think I have practiced flexbox pretty well with this project.
